# shaders-island

Embed moonshine WebGL shaders (same module as Next):

```ts
import { useFragmentShader } from "@tschk/moonshine-shaders";
// or in a Next client island:
import { useFragmentShader } from "@tschk/moonshine-next/shaders";
```

```bash
bun install
cd examples/shaders-island
bun run dev
# → http://localhost:5179
```
