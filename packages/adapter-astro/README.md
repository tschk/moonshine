# `@tschk/moonshine-astro`

Astro adapter for Moonshine. Re-exports moonshine for Astro client islands.

```tsx
"use client";
import { createSignal, useSignal } from "@tschk/moonshine-astro";
```

Use with React islands (`client:load`, etc.). Peer: `astro`, `react`,
`react-dom`.

See [Moonshine README](../../README.md).
