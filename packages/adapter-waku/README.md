# `@tschk/moonshine-waku`

Waku client-island adapter for Moonshine. Re-exports moonshine and Waku router
helpers.

```ts
import { createSharedIslandSignal } from "@tschk/moonshine-waku";
import { Link, useWakuPathSignal } from "@tschk/moonshine-waku/router";
```

Peer: `waku`, `react`, `react-dom`.

See [Moonshine README](../../README.md).
