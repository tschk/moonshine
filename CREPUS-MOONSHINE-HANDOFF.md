# Crepus-Moonshine Architecture Rewrite — Handoff Prompt

## Goal

Rewrite the `crepus-moonshine` package so that:

1. `.crepus` parsing is done by the **Rust** parser (`crepuscularity-core`), compiled to WASM and published as an npm package — not duplicated in TypeScript
2. CSS classes from `.crepus` files are **preserved as className** on DOM elements — not converted to inline styles. UnoCSS/Tailwind handles styling
3. The Rust `crepus web build --emit moonshine` emits **real TSX with className** preserved from the original `.crepus` — not `renderCrepusIr(ir)` wrapping JSON
4. Sites that are content-heavy (tsc.hk, inauguration) use `.crepus` files. Sites that are app-like (alpenglow, omi-v4) use `.tsx` directly

## Repos involved

- `~/projects/crepuscularity` — Rust CLI + parser + View IR types
- `~/projects/moonshine` — Bun-first web framework, includes `packages/crepus-moonshine`
- `~/projects/tsc.hk` — content site, should use `.crepus`
- `~/projects/inauguration/docs-site` — content site, should use `.crepus`
- `~/projects/alpenglow/site` — app-like site, should use `.tsx` directly
- `~/projects/omi-v4/site/web-moonshine` — app-like site, should use `.tsx` directly

## Architecture

```
.crepus file
    │
    ▼
┌─────────────────────────────┐
│ crepuscularity-core (Rust)  │  ← single parser, already exists
│ .crepus → ViewIr            │
└──────────┬──────────────────┘
           │
     ┌─────┴──────┐
     │            │
     ▼            ▼
  WASM         Native binary
     │            │
     ▼            ▼
@tschk/       crepus CLI
crepus-wasm   (web build --emit moonshine)
(npm pkg
 with TS shim)
     │
     ▼
@tschk/crepus-moonshine
  - imports parseCrepus from @tschk/crepus-wasm
  - renders ViewIr → React elements
  - preserves CSS classes (className)
  - NO inline style conversion
  - UnoCSS/Tailwind handles styling
     │
     ▼
moonshine server serves it
```

## Step 1: Rust — Add `classes` field to ViewNode

**File:** `~/projects/crepuscularity/crates/crepuscularity-native/src/ir.rs`

The `ViewNode` enum variants currently map UnoCSS classes to `ViewStyle` fields and **lose the original class names**. For web rendering we need the original classes preserved.

Add a `classes: Vec<String>` field to every `ViewNode` variant that has a `style` field. The parser in `crepuscularity-core` should populate this with the original class tokens from the `.crepus` file.

Example — `ViewNode::Stack`:

```rust
Stack {
    axis: StackAxis,
    classes: Vec<String>,  // ← ADD THIS
    #[serde(skip_serializing_if = "Option::is_none")]
    spacing: Option<f32>,
    // ... rest unchanged
    children: Vec<ViewNode>,
},
```

Do this for ALL variants: `Text`, `If`, `ForEach`, `Stack`, `Button`, `Toggle`, `Checkbox`, `Slider`, `Progress`, `Meter`, `Badge`, `Divider`, `Spacer`, `Dropzone`, `FilePicker`, `Image`, `WebView`, `Scroll`, `List`, `ListItem`, `SlotRotate`, `Input`, `Picker`, `Tabs`.

Then update the parser in `crepuscularity-core` to populate `classes` with the raw class tokens from the template (the words after the tag name that aren't attributes or text).

**Important:** Bump `IR_VERSION` from 5 to 6 since this is a schema change.

## Step 2: Rust — Fix `emit_moonshine` to preserve classes

**File:** `~/projects/crepuscularity/crates/crepuscularity-cli/src/web/emit.rs`

The current `emit_moonshine` function was just rewritten to emit real JSX with inline styles. **Revert this** — instead emit JSX that preserves the original CSS classes via `className`.

Replace `emit_moonshine` with a function that:

- Walks the `ViewIr` tree
- Emits real JSX elements (`<div>`, `<span>`, `<button>`, `<a>`, etc.)
- Puts the original classes on each element as `className="text-zinc-100 bg-zinc-950 ..."`
- Does NOT convert ViewStyle to inline CSS
- Maps ViewNode kinds to HTML tags:
  - `Stack` → `<div>` with flex direction via className (preserve original classes)
  - `Text` → `<span>`
  - `Button` → `<button>`
  - `Image` → `<img>`
  - `List` → `<ul>` or `<ol>`
  - `ListItem` → `<li>`
  - `Scroll` → `<div>` (classes handle overflow)
  - `Divider` → `<hr>`
  - `Spacer` → `<div>`
  - `Badge` → `<span>`
  - `Toggle` → `<button role="switch">`
  - `Checkbox` → `<label><input type="checkbox" /></label>`
  - `Slider` → `<input type="range">`
  - `Progress` → `<progress>`
  - `Meter` → `<meter>`
  - `Input` → `<input>` or `<textarea>`
  - `Picker` → `<select>`
  - `If` → `{condition ? (<then />) : (<else />)}`
  - `ForEach` → `{items.map((item, i) => (<body />))}`
  - `Tabs` → `<div>` with buttons + panels
  - `WebView` → `<iframe>`

  - `FilePicker` → `<label><input type="file" /></label>`

## Step 3: WASM — Compile crepuscularity-core to WASM + publish as npm package

Create a new crate or use an existing one in `~/projects/crepuscularity/crates/` that:

1. Depends on `crepuscularity-core` and `crepuscularity-native`
2. Exports a `parse_crepus(source: &str) -> ViewIr` function via `wasm-bindgen`
3. Is built with `wasm-pack build --target web --out-dir pkg`
4. The `pkg/` output is published to npm as `@tschk/crepus-wasm`

Steps:

```bash
cd ~/projects/crepuscularity
# Create a new crate crepuscularity-wasm
cargo new crates/crepuscularity-wasm --lib
# Add to workspace Cargo.toml
# Add deps: crepuscularity-core, crepuscularity-native, wasm-bindgen, serde, serde_json
# Add crate-type: ["cdylib", "rlib"]
# Write src/lib.rs:
```

```rust
use wasm_bindgen::prelude::*;
use crepuscularity_core::context::TemplateContext;
use crepuscularity_native::{render_template_to_ir, ViewIr};
use serde_json;

#[wasm_bindgen]
pub fn parse_crepus(source: &str) -> JsValue {
    let ctx = TemplateContext::new();
    let ir = render_template_to_ir(source, &ctx).unwrap_or(ViewIr { version: 0, root: vec![] });
    serde_wasm_bindgen::to_value(&ir).unwrap_or(JsValue::NULL)
}

#[wasm_bindgen]
pub fn parse_crepus_json(source: &str) -> String {
    let ctx = TemplateContext::new();
    let ir = render_template_to_ir(source, &ctx).unwrap_or(ViewIr { version: 0, root: vec![] });
    serde_json::to_string(&ir).unwrap_or_else(|_| "{}".to_string())
}
```

Build and publish:

```bash
cd ~/projects/crepuscularity
wasm-pack build crates/crepuscularity-wasm --target web --out-dir pkg
# Create package.json in pkg/ with name "@tschk/crepus-wasm"
# Publish: cd pkg && npm publish
```

Create a TS shim package `@tschk/crepus-wasm` that exports:

```typescript
export function parseCrepus(source: string): ViewIr;
```
